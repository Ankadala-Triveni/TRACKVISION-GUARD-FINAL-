Security Tradeoff Document: JWT is stored in localStorage. While highly convenient for decoupled single-page application setups and cross-domain APIs, it is vulnerable to Cross-Site Scripting (XSS) if malicious scripts are injected. For production environments, storing the token in HTTP-Only, Secure, SameSite=Strict cookies is recommended to block script access entirely.
